# 네이버 블로그 — 네이버 조작은 사람이 한다

네이버에는 자동 발행 경로가 없다. 그래서 이 저장소는 **글을 만드는 데까지만
자동화하고, 네이버 화면을 만지는 일은 전부 사람이 한다.** 자동화는
`npm run naver` 가 만들어 주는 붙여넣기 패키지에서 끝난다.

```text
글 작성 (기존 파이프라인, src/content/posts/)   ← 자동
        ↓
npm run naver -- <글.md>  →  naver-package/<슬러그>/  ← 자동
        ↓
편집기에 붙여넣기 · 이미지 업로드 · 발행         ← 사람
```

## 왜 여기서 멈추는가

1. **공식 API가 없다.** 네이버는 외부에서 글을 올리는 블로그 글쓰기 API를
   2020년 5월 광고성 도배 때문에 종료했고 복구하지 않았다. Blogspot
   자동화(`docs/routines/blogspot.md`)가 쓰는 Blogger API v3 같은 것이
   네이버에는 없다.
2. **브라우저 자동화는 약관이 막는다.** 네이버 이용약관은 사전 허락 없는
   자동화 수단으로 로그인·게시물 게재·클릭을 하는 것을 제한한다. 기술적으로
   가능한 것과 해도 되는 것은 다르다.
3. **걸렸을 때 잃는 것이 크다.** 제재나 저품질 판정은 글 한 편이 아니라 블로그
   전체에 걸린다. 매 편 5분을 아끼려고 감수할 위험이 아니다.

2026-09-04에 Playwright로 편집기에 직접 타이핑하는 스크립트
(`scripts/naver-blog/post_to_naver.py`)를 만들었다가 위 이유로 지웠다.
**다시 만들지 않는다.** 이 문단은 그 판단을 기억하기 위해 남긴다.

## 쓰는 법

```bash
npm run naver -- src/content/posts/2026-09-03-example.md
```

`naver-package/<슬러그>/` 에 다섯 개가 생긴다. 이 폴더는 `.gitignore` 에 있다.

| 파일 | 어디에 붙이나 |
| --- | --- |
| `01_title.txt` | 제목 |
| `02_body.txt` | 본문 |
| `03_tags.txt` | 태그 (`#태그` 형태) |
| `04_references.txt` | 본문 끝 출처 목록 |
| `publish-checklist.md` | 붙여넣기 전에 읽는다 |

## 본문이 어떻게 바뀌나

네이버 편집기는 마크다운을 모른다. 그래서 다음을 미리 처리한다.

| 원문 | 패키지 |
| --- | --- |
| `6\~12억원` | `6~12억원` — 이 저장소가 취소선 사고 때문에 넣어 둔 escape를 되돌린다 |
| `**47.2**%` | `47.2%` — 굵게 표시는 붙여넣은 뒤 사람이 지정한다 |
| `[제목](url)` | `제목` (링크는 `04_references.txt` 로 모은다) |
| 80자에서 접힌 문단 | 한 줄로 편다. 접힌 채 붙이면 줄바꿈이 그대로 들어간다 |
| `## 소제목` | `#` 없는 줄. 어느 줄이 소제목이었는지는 체크리스트에 남는다 |
| `- 항목` | `· 항목` |
| 표 · 코드블록 | 손대지 않는다. 체크리스트가 "직접 다시 만들라"고 경고한다 |
| 이미지 | 본문에서 빼고 체크리스트에 파일 목록으로 남긴다. 업로드는 사람이 한다 |

`category: finance` 인 글에는 투자 권유가 아니라는 고지를 남기라는 항목이
체크리스트에 자동으로 붙는다.

## 이 도구가 하지 않는 것

- 네이버 로그인. 하지 않는다.
- 편집기 입력·임시저장·발행. 하지 않는다.
- 서식·이미지 이관. 문단 텍스트까지만 옮긴다.
- 예약 실행. `docs/routines/` 에 등록하지 않는다 — 사람이 있을 때만 돈다.

## 조사에 네이버 검색 API를 쓰지 않는다

네이버 검색 API는 제목·URL·요약만 주는 검색기이지 CMS가 아니고, 검색 결과를
AI 입력·학습·평가에 쓰는 것을 제한하는 개정이 2026년 9월부터 적용된다. 이
저장소의 조사는 원래 일반 웹 검색과 1차 출처(공시·통계·논문)를 쓰므로 바꿀
것은 없다. 새로 붙이지도 않는다.
