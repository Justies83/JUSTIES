# 네이버 블로그 — 반자동 발행 도우미

네이버는 외부 프로그램이 대신 글을 올리는 공식 API를 2020년 5월에 어뷰징
(광고성 도배글) 때문에 완전히 종료했다. 그래서 Blogspot 자동화
(`docs/routines/blogspot.md`)처럼 API로 무인·예약 발행하는 방법은 없다.

남는 방법은 브라우저 자동화뿐이고, 여기서는 **일부러 완전 자동화하지
않는다.** 이 도구는 제목·본문을 글쓰기 화면에 채워 넣기만 하고, **발행
버튼은 항상 사람이 직접 누른다.**

| | |
| --- | --- |
| 본체 | `scripts/naver-blog/post_to_naver.py` |
| 실행 위치 | **사용자 자신의 PC에서만.** 원격 세션·CI에서 실행하지 않는다 |
| 발행 | 자동으로 하지 않는다. 채워 넣은 뒤 사람이 확인하고 누른다 |
| 예약 실행 등록 | 하지 않는다 — 이 문서는 `docs/routines/README.md` 표에 없다 |

## 왜 로컬에서만, 왜 반자동인가

1. **로그인은 사람이 해야 한다.** 네이버는 낯선 IP·기기에서 로그인하면
   캡차·2단계 인증을 띄운다. 데이터센터 IP(GitHub Actions 등)에서 무인
   로그인을 시도하면 거의 반드시 걸린다. 그래서 첫 로그인은 이 PC의 실제
   브라우저 창에서 직접 하고, 그 세션을 `scripts/naver-blog/.profile/` 에
   남겨 다음 실행부터 재사용한다. 이 폴더는 `.gitignore` 에 있다 —
   **커밋되지 않고, 커밋해서도 안 된다.** 로그인 세션이 통째로 든
   비밀번호나 마찬가지다.
2. **매크로로 보일 위험이 있다.** 네이버 약관상 이런 자동화는 매크로로
   분류될 수 있고, 걸리면 그 블로그가 "저품질" 판정을 받거나 제재될 수
   있다. 발행까지 자동화하면 실수 한 번(예: 셀렉터가 옛 화면을 가리켜
   엉뚱한 내용이 올라가는 것)을 되돌릴 수 없으니, **사람이 마지막으로
   확인하는 단계를 남겨 둔다.**
3. **에디터가 스마트에디터 ONE이라 서식이 온전히 옮겨지지 않는다.** 이
   도구는 마크다운을 문단 텍스트로만 바꿔 타이핑한다. 굵게·목록·표·이미지
   서식은 옮기지 않으므로, 채워 넣은 뒤 사람이 다듬어야 한다.

## 준비

```bash
pip install -r scripts/naver-blog/requirements.txt
python3 -m playwright install chromium
```

## 쓰는 법

```bash
python3 scripts/naver-blog/post_to_naver.py src/content/posts/2026-09-03-example.md --blog-id <네이버ID>
```

1. 브라우저 창이 뜬다. 첫 실행이면 로그인 화면이 보인다 — 직접
   로그인하고(캡차·2단계 인증 포함) 글쓰기 화면이 보이면 터미널로 돌아와
   Enter를 누른다. 다음 실행부터는 세션이 남아 있어 이 단계를 건너뛴다.
2. 제목·본문이 자동으로 채워진다.
3. **카테고리·태그·대표 이미지·서식을 직접 확인한다.**
4. 발행 버튼은 **직접 누른다.**

`--headless` 로 창을 숨길 수 있지만, 첫 로그인이나 문제를 확인할 때는
쓰지 않는다 — 무엇이 잘못됐는지 눈으로 봐야 고칠 수 있다.

## 실패하면

네이버가 화면 구조(클래스명)를 바꾸면 셀렉터가 깨진다. 스크립트가
"mainFrame을 찾지 못했다" 나 "입력란을 찾지 못했다" 로 멈추면:

1. `--headless` 없이 다시 실행해 실제로 무엇이 다른지 본다.
2. 브라우저 개발자 도구(F12)로 제목/본문 입력란의 클래스를 확인한다.
3. `post_to_naver.py` 의 `.se-title-text` / `.se-text-paragraph` 셀렉터를
   확인한 값으로 고친다.

이 도구가 기대하는 구조(스마트에디터 ONE, `iframe#mainFrame` 안의
`.se-title-text`/`.se-text-paragraph`)는 이 문서를 쓴 시점 기준이며, 네이버가
언제든 바꿀 수 있다.

## 이 도구가 하지 않는 것

- 예약·무인 실행. 사람이 매번 직접 켠다.
- 발행. 항상 사람이 마지막 버튼을 누른다.
- 서식·이미지 이관. 문단 텍스트만 옮긴다.
- 로그인 자동화. 캡차·2단계 인증은 사람이 처리한다.
