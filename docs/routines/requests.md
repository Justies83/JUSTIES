# 글 요청 처리 실행

4시간마다. 사용자가 `/admin` 의 **글 요청** 에 넣어 둔 주제가 있으면 쓴다.

## 먼저 이것만 실행한다

```bash
node scripts/pending-requests.mjs
```

**대기 중인 요청이 없으면 아무것도 하지 말고 "대기 중인 요청 없음" 이라고만
보고하고 끝낸다.** 뉴스 브리핑은 아침 예약이 담당하므로 이 실행에서는 하지 않는다.

## 요청이 있으면

`docs/daily-brief.md` 의 **"절차 0 — 요청부터 확인한다"** 를 읽고 그대로 따른다.
원문 확인 의무, 사실 / 해석 / 미확인 분리, 이미지 저작권 규칙, 도표 규격이
그 문서에 있다.

뉴스 브리핑과 달리 **요청은 섹션 제한이 없다.** 리뷰나 육아 주제를 요청해도 쓴다.
다만 직접 겪어야 아는 것(맛집 방문기, 기기 실사용)은 자료로 대신할 수 없으니,
그런 요청은 무엇이 필요한지 보고하고 남겨 둔다.

## 끝낼 때 반드시

처리한 요청 파일의 `상태` 를 `완료` 로, `결과` 를 글 주소로 고쳐서
**같은 커밋에 포함한다.** 이것을 빠뜨리면 다음 실행이 같은 요청을 또 쓴다.

마지막에 무엇을 썼는지, 또는 왜 쓰지 않았는지 보고한다.
