## push 권한 확보 — 가장 먼저 할 일

글을 쓰기 전에 이것부터 한다. `add_repo` 도구를 아래 값으로 호출한다.

- owner: `Justies83`
- repo: `JUSTIES`
- access: `push`

이 저장소는 이미 클론돼 있어 **읽기는 되지만**, 실제로 커밋을 push하려면
이 호출로 **쓰기 권한을 따로** 받아야 한다. 2026-08-29\~08-31 사이 실행들이
글을 다 쓰고 빌드까지 통과시키고도 push가 "저장소가 세션의 허용 목록에
없다(access denied by the git proxy)"는 오류로 거부된 적이 있다 — 이 호출을
빠뜨렸기 때문이다.

이 호출이 실패하거나 거부되면 **글을 쓰기 시작하지 않는다.** 그 사실만
보고하고 실행을 끝낸다. 로컬에 커밋을 쌓아 두는 것은 의미가 없다 — 다음
실행은 새 컨테이너로 뜨기 때문에 그 커밋을 이어받지 못한다.

```bash
npm ci
npm run build
npx astro check
```

셋이 모두 통과한 뒤에만 커밋하고 push한다. 배포는 GitHub Actions가 하므로
Cloudflare 토큰은 필요하지 않다.

## 한 편씩 push한다

**다섯 편을 다 쓴 뒤에 몰아서 커밋하지 않는다.** 한 편을 완성할 때마다 빌드하고
커밋하고 push한 뒤 다음 편으로 넘어간다. 이 실행이 중간에 끝나도 그때까지 쓴 글은
사이트에 남아야 한다.

이 규칙을 지키지 않아 2026-08-25와 08-26 두 번의 실행이 각각 13분·17분 동안
작업하고도 커밋을 하나도 남기지 못했다.

실행을 끝내기 전에 확인한다.

```bash
git status --short     # 커밋 안 된 글이 남아 있으면 지금 커밋하고 push한다
git log origin/claude/personal-editable-homepage-31hofg --oneline -5
```

무엇을 발행했고 무엇을 버렸는지, 버린 이유를 함께 보고한다.
발행한 글은 커밋 해시와 함께 적는다.

항목 하나하나는 근거가 부실하면 버리는 것이 맞다. 다만 **하루 전체를 비우는 것은
다른 문제다** — 1번(미장 요약)은 증시 마감·환율처럼 매일 확인 가능한 재료가
있으므로, 아무것도 못 쓸 상황이면 최소 그 한 편은 쓴다. `docs/daily-brief.md` 의
"하루 최소 한 편" 을 따른다.
